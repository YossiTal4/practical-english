# 10 random words option Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a home-screen card that starts a 10-question quiz of random words from all levels.

**Architecture:** One new level value (`random10`) handled in the existing quiz flow in `app.js`, a new card in `index.html`, and a cache bump in `sw.js`. No new dependencies.

**Tech Stack:** Vanilla JavaScript, HTML, Node.js for the self-check (no build step).

**Spec:** None. The user's request ("add an option of 10 random words") is the spec, and the user opted out of questions.

## Global Constraints

- No new dependencies.
- Cache name in `sw.js` bumped on every release (`wordquiz-v61`).
- Hebrew UI text, matching the existing cards.

## Review Focus

- Word list smaller than 10 words: the quiz must not crash (current data has thousands of words, so this is a guard, not a live case).
- Clicking the card twice in a row: the second quiz starts fresh, with question 1 of 10.

### Task 1: Random-10 quiz option

**Files:**
- Modify: `app.js` (`getWordsForLevel`, `getWrongAnswers`, level click handler)
- Modify: `index.html` (level grid, new card)

**Interfaces:**
